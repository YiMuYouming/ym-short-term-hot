三、PostgreSQL（ymhot_test）
- 本机原先没有任何 PostgreSQL；Docker 未运行；brew install 在沙箱内
  被内层 sandbox-exec 拒绝（sandbox_apply: Operation not permitted）。
- 解决方案：npm 包 @embedded-postgres/darwin-arm64（自包含通用二进制，
  arm64 slice，rpath 相对），落盘于：
  /Users/yimu/AgentScratch/workbuddy/ymhot-pg/
  - 包：package/native/{bin,lib,share}（initdb / postgres / pg_ctl）
  - 数据目录：/Users/yimu/AgentScratch/workbuddy/ymhot-pg/data
    （initdb -U yimu --auth=trust --encoding=UTF8 --locale=C）
  - 启动：pg_ctl -D data -o "-c listen_addresses=127.0.0.1 -c port=5432" start
  - 当前以守护进程方式监听 127.0.0.1:5432（仅本机回环，trust 认证，无对外暴露）。
- 常驻化未完成：~/Library/LaunchAgents/cn.yimu.ymhot.postgresql.plist 已写好
  （Label cn.yimu.ymhot.postgresql，RunAtLoad+KeepAlive），但 launchctl
  bootstrap/load 在当前登录会话内恒报 "Bootstrap failed: 5: Input/output error"
  （与 2026-10-15 记录的 launchd 会话级 EIO 陷阱一致，非沙箱、与 plist 内容无关）。
  需要用户在自有终端执行一次即可常驻：
    launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/cn.yimu.ymhot.postgresql.plist
  或重启登录后自动生效。SH-02/SH-03 开工前需确认该服务在跑。
