## 1. 为什么要做 V2 极简减法重构？

旧版 V1（已归档至 [`docs/archive/v1-aihot-heavy/`](archive/v1-aihot-heavy/)）直接照搬了 AIHOT 整栋科技资讯大楼的外壳（精选、日报、周报、主题、身位桶、多维概念卡片），导致**界面臃肿、重点模糊、真实盘中数据与题材原因尚未对齐**。

V2 的核心原则是**「克制、真实、一页直达」**：
- 保留 [`bridge/`](../bridge/) 已验证的 Python 数据管道与三大社区（东财股吧/淘股吧/雪球）采集内核；
- **砍掉一切花哨概念与无效外壳**，打开网页（`/` 或 `/radar`）只看最纯粹的 **2 个入口视角 + 1 个共用个股详情**：
  1. **视角 1：热门板块视角**
     - **(a) 排热门板块**：基于真实数据（同花顺热点 `legacy_hot_rank` 题材涨停统计 + `market_intraday_state` 涨停池 + `industry_flow` 行业资金 + `themes_v2.json` 60 大题材），按板块热度/涨停家数从高到低排列；**点开某个热门板块，直接列出该板块下的热门股列表**。
     - **(b) 点开热门股看详情**：展示这只股**为什么火**（真实涨停原因 `reason` / 同花顺热榜上榜原因 `rank_reason` / 几连板 / 涨跌幅 / 成交额 / 所属板块）+ **各平台（东财股吧、淘股吧、雪球）对这只股的真实评价与高赞讨论**。
  2. **视角 2：热门股 Top 50 视角**
     - 直接展示同花顺热榜 + 东方财富人气榜 + 当日涨停池合成的**全市场 Top 30~50 热门股榜单**（排名、代码名称、涨跌幅、连板数、所属板块、一句话为什么火）；
     - **点开任意热门股**：同样进入共用的个股详情抽屉/面板，看它为什么火 + 各社区平台真实评论。

## 2. 真实数据源摸底结论（2026-10-17 实测已确认）

通过 `YM-data-pipeline` 公共入口 `from ym_stock_data import query` 实测可用、字段清晰的真实接口：

| 用途 | 管道 Intent 与参数 | 实测状态与关键字段 |
| :--- | :--- | :--- |
| **同花顺热点股 + 涨停原因 + 热门板块统计** | `query("legacy_hot_rank")` | ✅ 返回 59 只热股，含 `code`、`name`、`zhangfu`、`reason`（如 `"卫星通信芯片+低空经济+卫星应用"`，天然拆出题材标签與为什么火）、`chengjiaoe`；同时自带 `reason_stats`（如 `{"低空经济": 11, "飞行汽车": 5, "机器人": 5...}`）直接给出当日最热板块排行！ |
| **同花顺热榜 Top 50（含 AI 详细上榜原因）** | `query("market_hot_rank", source="ths", trade_date=<最近交易日>, limit=50)` | ✅ 传入最近交易日（可从 `market_intraday_state.trade_date` 获取）即返回完整热股榜，含 `rank`、`pct_change`、`concept`（概念数组）、**`rank_reason`（完整的「行业原因 + 公司原因」文本，直接回答“这只股为什么火”）**！ |
| **东方财富人气榜 Top 50** | `query("market_hot_rank", source="dc", limit=50)` | ✅ 无需传日期即返回实时 Top 50，含 `ts_code`、`ts_name`、`rank`、`pct_change`。 |
| **盘中涨跌停池与连板高度** | `query("market_intraday_state")` | ✅ 返回 `trade_date`（如 `"20261016"`）及 `limit_up`（61 只涨停股），含 `code`、`name`、`pct`、`amount`、`board`（几连板）、`industry`（所属行业）、`seal_time`（封板时间）。 |
| **行业板块涨幅与领涨股** | `query("industry_flow")` | ✅ 返回 90 个同花顺行业，含 `industry`、`pct_change`（板块涨幅）、`net_amount`（净流入）、`lead_stock`（领涨股）。 |
| **60 大高频短线题材词典** | `docs/aihot_research/dict/themes_v2.json` | ✅ Grok 第六波已核验的 60 个题材、别名与 200+ 代表股。 |

## 3. 分阶段实施拆解（PM 谷米 ⇄ 实施 稳米）

为保证每一步都干净可控，V2 极简版拆为两个紧凑阶段（也可按需合并派单）：

| 阶段单号 | 阶段名称 | 核心交付内容 | 验收门禁 |
| :--- | :--- | :--- | :--- |
| **`LITE-01`** | **真实热门板块与热门股 Top 50 数据底座打通 (`bridge/`)** | 1. 切换 `dict/themes_v2.json`（60 题材）；<br>2. 在 `bridge/pipeline_loader.py` 接入真实字段：对齐 `market_intraday_state` 的 `board`/`pct`/`industry`/`seal_time`，用 `trade_date` 调通 `market_hot_rank(source="ths")` 拿到 `rank_reason`（为什么火）與 `concept`，并接入 `legacy_hot_rank` 的 `reason`（涨停原因拆解题材）与 `reason_stats`；<br>3. 产出清晰的「热门板块列表（按板块内涨停数/热股数排序，内含该板块热门股）」与「全市场热门股 Top 50（含同花顺/东财排名、连板、为什么火 `whyHot`、三社区评论）」。 | 1. `bridge` 离线单测 100% 全绿；<br>2. 跑通真实 `--live-smoke` 快照生成，验证热门板块不再出现大面积“未归题材”，每只热门股都有明确的板块归属与 `whyHot`（为什么火/涨停原因）。 |
| **`LITE-02`** | **前端极简减法重构（2 个视角 + 1 个个股详情）** | 1. 隐藏/精简 AIHOT 冗余导航外壳，首页 `/` 直接指向极简短线看盘页；<br>2. 砍掉复杂的「空间板/20cm弹性/容量中军」五分身位桶与花哨指标卡片，页面顶部只留 **`[ 热门板块 ]` ⇄ `[ 热门股 Top 50 ]`** 两个干净 Tab；<br>3. **Tab 1（热门板块）**：左侧/上方按热度排板块（板块名、涨停数/热股数、核心领涨股），点开板块直接展示板块内热门股表格；<br>4. **Tab 2（热门股 Top 50）**：一张克制的表格（排名、股票、涨跌幅、几连板、所属板块、为什么火摘要、社区热度）；<br>5. **共用个股详情面板**：点开任意股票，上方展示**「为什么火（涨停/热榜详细原因 + 硬数据）」**，下方按平台（全部 / 淘股吧 / 雪球 / 东财股吧）展示**真实社区评价与重要帖子**。 | 1. `npm run typecheck` 与 `npm run build -w @aihot/web` 零报错；<br>2. `tests/architecture.test.ts` 与模块测试全绿；<br>3. 3088 端口真实页面验证：打开即看懂，两视角切换流畅，点板块看股、点股看「为什么火 + 社区评论」一目了然。 |
