## 2. 具体实施要求

### 2.1 缺失值与降级状态诚实化展示（消灭截图 3 自相矛盾）
1. **连板标签格式化函数 `formatBoardBadge(stock, intradayDegraded)`**：
   - `stock.boardCount >= 2` → 显示 `"${stock.boardCount} 连板"`（红色高亮徽章）；
   - `stock.boardCount === 1` → 显示 `"首板"`（符合 A 股短线术语，不再显示 `"1 连板"`）；
   - `stock.boardCount === 0`：
     - 若 `stock.changePct !== null && stock.changePct >= 9.8` → 显示 `"涨停/待核连板"`；
     - 若 `intradayDegraded` 为 `true` 且 `stock.limitReason` 非空 → 显示 `"连板待补"`；
     - 其余情况在表格中不显示多余灰字，在抽屉硬指标卡中显示 `"未连板"`。
2. **封板时间格式化函数 `formatSealTime(stock, intradayDegraded)`**：
   - 若 `stock.sealTime` 非空 → 直接显示 `stock.sealTime`（如 `"09:30"`）；
   - 若 `stock.sealTime` 为空但 `stock.boardCount > 0`（如冰山冷热 4 连板但盘中池降级未返回封板时间）→ 显示 **`"封板时间待补"`**（彻底消灭 `"4 连板"` 旁边写 `"未封板/非涨停"` 的自相矛盾！）；
   - 若 `stock.sealTime` 为空且 `stock.boardCount === 0`：
     - 当 `stock.changePct !== null && stock.changePct >= 9.8` 时显示 `"封板时间待补"`；
     - 否则显示 `"未涨停"`。
3. **顶部时间感知优化**：
   - 将页头右侧时间文案从笼统的 `"实时"` 改为明确展示：**`交易日 ${snapshot.tradeDate} · ${formatUpdatedAt(snapshot.generatedAt)} 更新`**（若 `snapshot.tradeDate` 存在），让用户在盘前/盘后一眼分清当前看的是哪一天的行情。

### 2.2 视角 1（`[🔥 热门板块]`）主线聚焦与卡片紧凑化（解决截图 1 列表过长）
1. **左侧板块列表“主线默认展示 + 单股长尾折叠 + 快速过滤”**：
   - 在左侧板块列表顶部增加一个紧凑的本地过滤框（`placeholder="筛选板块或成分股..."`）；
   - 当未输入过滤词时，默认展示**核心主线板块**（满足 `stockCount >= 2` 或 `limitUpCount >= 2` 的板块；若不足 12 个则补足前 15 个板块）；
   - 其余只有 1 只热门股的长尾板块默认收起，在列表底部提供 **`展开其余 N 个单股异动概念 ▾`** / **`收起单股概念 ▴`** 切换按钮（若 URL `?theme=` 选中的板块在折叠区，则自动展开或置顶显示）；
   - 板块卡片的领涨股文案：当 `leaderStock.changePct !== null && leaderStock.changePct > 0` 时显示 **`领涨 ${name} +${pct}%`**；当 `leaderStock.changePct <= 0` 时改称 **`代表 ${name} ${pct}%`**（消灭“领涨 芒果超媒 -3.67%”）。
2. **右侧板块成分股行（`ThemeStockRow`）双行紧凑化**：
   - 移除原本在卡片底部横跨整行的长条 `SentimentBar`；
   - 改为紧凑双行卡片（每张高度控制在 ~60px）：
     - 第一行：左侧 `股票名 + 代码 + 首板/N连板徽章 + 封板时间`，右侧 `涨跌幅（大号等宽字体） + 成交额`；
     - 第二行：左侧一句话 `为什么火（limitReason 或 whyHot 首句，单行截断）`，右侧紧凑社区徽章（如 `15帖 · 偏多 60%` 或 `3帖 · 分歧`）。

### 2.3 视角 2（`[📈 热门股 Top 50]`）表格对齐与小样本情绪条修正（解决截图 2 视觉噪声）
1. **固定列宽与键盘无障碍**：
   - 表格启用 `table-layout: fixed` 并配置 `<colgroup>` 固定各列宽度比例；
   - 股票名称单元格内使用原生 `<button type="button">` 包裹股票名与代码，支持键盘 Tab 聚焦与回车打开抽屉；
   - 所属板块列最多展示 **2 个**板块胶囊，超出部分显示 `+N`；
   - 为什么火列固定 `line-clamp-2`，保证整张 Top 50 表格行高整齐划一。
2. **多空情绪条修正（`SentimentBar`）**：
   - 仅当 `totalPosts === 0` 时渲染全灰占位条并标注 `"暂无评论"`；
   - 只要 `totalPosts > 0`，无论 `label` 是否为 `"情绪中性"` 或 `"讨论平淡"`，都按真实的 `bullRatio / divergenceRatio / bearRatio` 渲染红/琥珀/绿三色比例条（解决 1 多 1 空 50% 对决被抹成全灰的问题）；
   - 当 `totalPosts < 5` 时，给比例条加上 `opacity-65` 并在文案旁标注 `(小样本)` 或直接显示 `${totalPosts}帖 · ${label}`，避免 1 条帖子显得像强共识。

### 2.4 共用个股详情抽屉（`StockDrawer`）信息层级重排与交互闭环（解决截图 3/4 阅读断层）
1. **头部快捷导航与状态重置**：
   - 抽屉头部提供 **`← 上一只`** / **`下一只 →`** 切换按钮（基于当前激活视角下的股票列表顺序切换），并支持键盘 `Escape` 关闭、`ArrowLeft` / `ArrowRight` 切换上一只/下一只；
   - 监听 `stock.code` 变化（`useEffect`）：切换股票时自动将评论平台筛选重置为 `"all"`、收起长文本展开状态，并将抽屉滚动容器滚回顶部（`scrollTop = 0`）。
2. **“为什么火”长文本折叠（首屏直达评论区）**：
   - 置顶醒目展示 **一句话涨停/热榜核心催化（`limitReason`）** + **6 格紧凑硬指标条（连板状态、封板时间、成交额、换手率、同花顺热榜、东财人气榜）**；
   - 下方展示 `whyHot` 详细逻辑：当 `whyHot` 长度超过 110 字符或包含换行时，默认截断展示前 3 行（`line-clamp-3`），并提供 **`展开完整逻辑 ▾` / `收起 ▴`** 按钮，让用户打开抽屉无需滚动即可同屏看到下方的多空情绪条与社区热帖！
3. **社区平台筛选 Tab 带计数 & 单帖详情升级**：
   - 平台切换按钮直接显示该股在各平台的帖子数：**`全部 (${allCount})`**、**`淘股吧 (${tgbCount})`**、**`雪球 (${xqCount})`**、**`东财股吧 (${emCount})`**（计数为 0 的 Tab 弱化透明度）；
   - 单帖卡片展示：
     - 平台徽章 + KOL/深度标签 + **单帖情绪徽章（看多红 / 看空绿 / 分歧琥珀 / 中性灰，读取 `post.sentimentLabel`）**；
     - 标题 `post.title`；若 `post.content` 非空且与标题不同，展示 2 行正文摘要（`line-clamp-2 text-xs text-ink-secondary`）；
     - 底部展示：作者、发布时间 `post.publishedAt`（格式化为 `MM-DD HH:mm`）、评论数/点赞数、以及 `查看原帖 ↗` 链接。
4. **样式变量清理**：
   - 清理 `radar-route.tsx` 中未定义的 `--page-max-board`、`fadeIn`、`fadeOut` 类名，统一使用 `app.css` 已定义的主题变量。
