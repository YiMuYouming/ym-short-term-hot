## 一、 必读：AIHOT 模块架构红线与避坑指南（谷米预审排雷）

在动手写 `modules/short-term-radar/` 前，必须严格遵守 [`tests/architecture.test.ts`](../tests/architecture.test.ts) 与 [`docs/architecture.md`](architecture.md) 强制检查的以下 4 条铁律：

1. **红线 A — 前端代码严禁跨越 HTTP 边界（`tests/architecture.test.ts` 第 49 行：`the web reaches the backend only over HTTP`）**：
   - `modules/short-term-radar/web.tsx` 及 `modules/short-term-radar/web/**`（或前端路由文件）**绝对不能** `import` 任何来自 `@aihot/backend`、`packages/backend`、`postgres` 或 `pg-boss` 的模块！
   - 前端路由 loader 只能通过 `apps/web/app/lib/api.server.ts` 的 `apiGet` / `loadOr404` / `cachedPage` 走 HTTP 请求 `/api/site/radar` 获取数据。
2. **红线 B — 严禁在代码中直接读取未登记的 `process.env.*`（`tests/architecture.test.ts` 第 150 行：`every environment variable the code reads is listed in a template`）**：
   - 在 `modules/short-term-radar/server.ts` 中读取 `.data/short-term-radar-snapshot.json` 时，**严禁直接写 `process.env.DATA_DIR` 或自定义新的 `process.env.YM_RADAR_...`**！
   - 必须统一通过 `import { config } from "@aihot/backend/config"`，使用 `path.join(config.dataDir, "short-term-radar-snapshot.json")`（或支持测试入参注入路径覆盖）。
3. **红线 C — 零冗余数据库表/列检查（`tests/architecture.test.ts` 第 118 行：`every table and column is used by the code that reads and writes the database`）**：
   - `SH-02` 的 [`bridge/run_bridge.py`](../bridge/run_bridge.py) 已经将完整的双视图结构化数据原子写入 `.data/short-term-radar-snapshot.json`（即 `path.join(config.dataDir, "short-term-radar-snapshot.json")`）。
   - 因此 **`SH-03` 无需新增任何 PostgreSQL migration 表**！`server.ts` 直接从 `path.join(config.dataDir, "short-term-radar-snapshot.json")` 读取并校验快照（若文件不存在则优雅降级返回空快照结构），既做到毫秒级响应，又 100% 规避未引用列导致 `architecture.test.ts` 失败的风险。
4. **红线 D — TypeScript 雙工程编译边界（`modules/tsconfig.json` vs `apps/web/tsconfig.json`）**：
   - [`modules/tsconfig.json`](../modules/tsconfig.json) 编译范围为：`["../site/modules/index.ts", "../site/modules/server.ts", "*/*.ts", "*/backend/**/*.ts", "*/api/**/*.ts", "*/scripts/**/*.ts", "*/tests/**/*.ts"]`（注意：它只包含 `.ts`，不包含 `.tsx`）；
   - [`apps/web/tsconfig.json`](../apps/web/tsconfig.json) 编译范围为：`app/**/*`、`../../site/**/*`、`../../modules/*/web.tsx`、`../../modules/*/web/**/*`；
   - 因此：**请将前端路由与组件放在 `modules/short-term-radar/web/` 目录下**（例如 `modules/short-term-radar/web/radar-route.tsx`），并在 `module.ts` 中声明：
     ```ts
     pages: [{ path: "radar", file: "web/radar-route.tsx", id: "short-term-radar" }]
     ```
     这样 [`apps/web/app/routes.ts`](../apps/web/app/routes.ts) 会自动解析为 `../../modules/short-term-radar/web/radar-route.tsx`，同时 `modules/tsconfig.json` 不会误编译 `.tsx` React 文件，`apps/web/tsconfig.json` 则会完整类型检查所有 `.tsx` 文件！
