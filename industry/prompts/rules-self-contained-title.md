
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：个股名 / 题材名 / 公司或机构名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是代码 / 日期 / 没信息量的 teaser（如 "300XXX"、"2026-10-15"、"早盘策略"、"重磅"）时，结合【来源】和正文把主体补进标题。例：原标题 "300XXX" + 来源 "淘股吧：XX 的实盘复盘" → "淘股吧实盘复盘：300XXX 三连板背后的算力接力"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体个股时，用上位词（如"某算力概念股"）兜底，绝不凭"行业常识"编一个具体代码 / 连板数 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / 复盘这类解释、分析、教程或复盘标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的政策、个股或龙虎榜数据，就改写成“发布 / 推出 / 落地 / 披露”。只有原标题明确宣布了发布、推出、落地或披露，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的公司、个股、题材名。
   例：原标题 "How a 20cm leader carried the optics theme" → "20cm 空间龙如何带起整条光模块主线"，不能写成 "某龙头发布光模块新产品"。
   例：原标题 "How to read tomorrow's auction after a limit-down" + 来源和正文明确是淘股吧复盘帖 → "淘股吧复盘：跌停次日竞价怎么看"，不能只写成缺主体的 "次日竞价怎么看"。
